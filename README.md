# Bad Apple!! на VK Капсуле Мини

Клип Bad Apple!! на панели часов колонки VK Капсула Мини: 4 семисегментные цифры, 28 сегментов с ШИМ-яркостью. Звук играет из динамика колонки, двоеточие мигает в такт громкости, кольцо сверху работает как белая светомузыка.

## Требования

Колонка:
- root-доступ по SSH;
- `aplay`, `mpg123`, `/usr/local/bin/clockdisp`, `/usr/local/bin/ringled`;
- сегменты панели в `/sys/class/leds/clock:d{1..4}:{a..g}`, точки двоеточия в `clock:colon:{top,bottom}`.

Компьютер:
- `python3` (только стандартная библиотека);
- `ffmpeg` с libmp3lame и soxr;
- `curl`, `ssh`, `scp`.

## Установка

```sh
./build.sh
./install.sh root@192.168.1.50
```

`build.sh` скачивает видео и звук из [rkk-2s/bad-apple](https://github.com/rkk-2s/bad-apple) (коммит зафиксирован, sha256 сверяется) и собирает кадры в `out/`.

`install.sh` копирует плеер и данные в `/root/badapple` на колонке, создаёт команду `badapple` и добавляет `dmix` в `/etc/asound.conf`. Старый конфиг сохраняется как `/etc/asound.conf.orig`. Без `dmix` `aplay` получает `Resource busy`, пока `bluealsa-aplay` играет Bluetooth-аудио.

На колонке занимает около 6 МБ.

## Запуск

На колонке:

| Команда | |
|---|---|
| `badapple` | запуск в фоне, не останавливается при обрыве SSH |
| `badapple --stop` | остановить |
| `badapple --fg` | в текущем терминале, остановка по Ctrl-C |
| `badapple --test` | первые 10 секунд |
| `badapple --orig` | исходные цвета (светится фон, а не силуэт), можно вместе с `--fg` и `--test` |

Переменные окружения:

| Переменная | По умолчанию | |
|---|---|---|
| `NOSOUND=1` | | без звука |
| `NORING=1` | | без кольца |
| `RING_BRIGHT` | `60` | яркость кольца, %. Двенадцать светодиодов на полном белом потребляют около 700 мА |
| `TITLE` | `BAD APPLE` | бегущая строка перед клипом, пустая строка отключает |
| `SCROLL_MS` | `200` | шаг бегущей строки, мс |
| `AV_DELAY_MS` | `85` | задержка картинки относительно старта `aplay` |

Итог прогона пишется в `/tmp/badapple.log`: сколько кадров показано и сколько пропущено.

## Как устроено

`gen_frames.py`:
- видео уменьшается до 48x28, по 12x28 на цифру; каждый пиксель отдаётся ближайшему сегменту, яркость сегмента равна среднему по его пикселям;
- картинка инвертируется, затем переводится в ШИМ с гаммой 2.0 (`GAMMA=1.6 ./build.sh` меняет гамму); чёрное начало и конец клипа гасятся;
- двоеточие показывает громкость по кадру с плавным спадом;
- кольцо: звук делится на 6 полос от 120 Гц до 6 кГц, каждой полосе соответствуют два симметричных светодиода; из уровня вычитается среднее за последнюю секунду, поэтому кольцо вспыхивает на ударах, а не горит постоянно; частота 15 кадров/с;
- звук пересэмплируется в 48 кГц стерео и кодируется в MP3 (VBR, `-q:a 2`), чтобы ALSA на колонке не пересэмплировала его линейно.

`player.sh`:
- пишет яркости напрямую в sysfs, один кадр занимает около 3 мс;
- время берётся из `/proc/uptime`; кадр, который опоздал на свой слот, пропускается, поэтому картинка не отстаёт от звука;
- звук: `mpg123 -s | aplay`; отсчёт начинается, когда `aplay` открыл звуковую карту, плюс один буфер `dmix` (4096 сэмплов при 48 кГц = 85 мс). Через микрофон колонки проверено, что с `mpg123` в конвейере звук стартует так же, как у `aplay` с WAV; сам `mpg123` в ALSA стартует на ~160 мс позже;
- кольцо работает в отдельном цикле: `ringled` перепривязывает SPI-драйвер при каждом вызове и тратит на это около 37 мс;
- при выходе гасит панель и кольцо, возвращает прежнюю яркость, ток и скорость прокрутки панели.

## Удаление

```sh
rm -rf /root/badapple /usr/local/bin/badapple
mv /etc/asound.conf.orig /etc/asound.conf
rc-service bluealsa-aplay restart
```

## Источники

Видео и звук взяты из репозитория [rkk-2s/bad-apple](https://github.com/rkk-2s/bad-apple) (автор [rkk-2s](https://github.com/rkk-2s), раньше аккаунт назывался CalvinLoke). Там Bad Apple!! выводится ASCII-графикой в консоль на Python. Сюда видео и звук не включены, `build.sh` скачивает их оттуда.
